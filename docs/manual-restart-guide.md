## 📋 重启步骤

### 步骤1：停止后端服务器

找到运行后端服务器的终端窗口，执行以下操作：

1. **按 `Ctrl+C`** 停止服务器
2. 等待看到类似提示：
   ```
   Server stopped
   ```
   或终端恢复到命令提示符

### 步骤2：重新启动后端服务器

在同一个终端窗口中，运行：

```bash

```

### 步骤3：验证启动成功

启动后，你应该看到：


## 🔧 故障排除

### 如果服务器启动失败

检查以下几点：

1. **端口占用**
   ```bash
   netstat -ano | findstr "3011"
   ```
   如果端口被占用，关闭占用的进程

2. **数据库连接**
   - 确保数据库正在运行
   - 检查 DATABASE_URL 配置

3. **依赖安装**
   ```bash
   npm install
   ```

### 如果V2没有生效

检查 .env 文件：
```bash
cat .env | grep AI_REVIEW_VERSION
# 应该看到：AI_REVIEW_VERSION=v2
```

如果没有，手动添加：
```bash
echo "AI_REVIEW_VERSION=v2" >> .env
```
