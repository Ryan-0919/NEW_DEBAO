# AI批改的业务逻辑详解

## 📚 法考主观题批改原理

### 核心概念

法考主观题批改基于**采分点制度**：
- 每道大题分为多个小问
- 每个小问有若干个采分点（rubric points）
- 每个采分点有固定分值
- 学生答案命中采分点 → 得分

---

## 🎯 当前系统的批改逻辑

### 1. 题目数据结构

**大题（Question）：**
```javascript
{
  id: "q_123",
  type: "subjective_case",
  score: 20,                    // 总分
  material: "某公司与员工...",  // 案例材料
  stem: "请回答以下问题：",
  questionMetaJson: {           // 小问配置
    subQuestions: [...]
  }
}
```

**小问（SubQuestion）：**
```javascript
{
  id: "sub_1",
  title: "小问(1)：本案中的证明责任如何分配？",
  maxScore: 10,                 // 该小问满分
  referenceAnswer: "赵某应对污染行为承担证明责任...",
  rubricGuidance: "重点考察学生对举证责任分配的理解",
  rubricPoints: [               // 采分点
    {
      id: "rubric_1",
      title: "污染行为证明责任",
      description: "指出白云制药厂排放废气的事实由赵某承担证明责任",
      maxScore: 5,
      score: 5
    },
    {
      id: "rubric_2", 
      title: "其他养殖户未受影响的证明责任",
      description: "指出该事实应由白云制药厂承担证明责任",
      maxScore: 5,
      score: 5
    }
  ]
}
```

**学生答案：**
```javascript
{
  questionId: "q_123",
  answerJson: {
    "sub_1": "本案中，白云制药厂排放废气的行为应由赵某证明...",
    "sub_2": "..."
  }
}
```

## 🤖 AI批改的核心任务

AI需要完成以下工作：

### 任务1：判断每个采分点是否命中 ✓

**输入：**
- 采分点：{ title: "污染行为证明责任", maxScore: 5 }
- 学生答案："白云制药厂排放废气的行为应由赵某证明"

**AI判断：**
```javascript
{
  id: "rubric_1",
  title: "污染行为证明责任",
  maxScore: 5,
  hit: true,              // ← 命中
  awardedScore: 5,        // ← 给5分
  comment: "学生正确指出了污染行为的证明责任由赵某承担"
}
```

### 任务2：生成正向划线（得分点标注）✓

**当前AI会做：**
```javascript
{
  id: "mark_1",
  highlight: "白云制药厂排放废气的行为应由赵某证明",  // 学生原文
  start: 10,
  end: 35,
  status: "score",        // 正向标注
  score: 5,               // 得几分
  comment: "命中采分点：污染行为证明责任（5分）"
}
```

### 任务3：生成错误划线（错误点标注）❌

**当前AI不做，但应该做：**

假设学生写了："本案中，应由白云制药厂证明污染行为存在"

这是**错误的**（主体写反了），AI应该标注：
```javascript
{
  id: "mark_2",
  highlight: "应由白云制药厂证明污染行为存在",
  start: 50,
  end: 68,
  status: "wrong",        // 错误标注
  comment: "证明责任主体错误。污染行为的证明责任应由原告赵某承担，而非被告白云制药厂。这是因为根据《民事诉讼法》，原告主张的事实由原告举证。"
}
```

### 任务4：识别遗漏点 ✓

**当前AI会做：**

如果学生没有提到"其他养殖户未受影响的证明责任"，AI会生成：
```javascript
{
  id: "missed_1",
  title: "遗漏其他养殖户未受影响的证明责任",
  score: 5,               // 丢了5分
  description: "答案没有说明该事实应由白云制药厂承担证明责任",
  suggestion: "补充说明该事实属于抗辩方向，应由白云制药厂承担证明责任"
}
```

### 任务5：生成综合点评 ✓

**当前AI会做：**
```javascript
{
  reviewComment: "你这一问的基本方向是对的，能够意识到证明责任需要结合具体事实来分配，这一点值得保留。但你遗漏了其他养殖户未受影响这一事实的证明责任分配。这个事实属于被告的抗辩理由，应当由被告白云制药厂承担证明责任。后面再写时，要把每一项事实背后的法律意义说得更清楚：谁主张该事实、该事实服务于哪一方的请求或抗辩、为什么应由该方承担证明责任。"
}
```

## ⚖️ 评分逻辑

### 评分公式

```javascript
// 小问得分 = 所有命中的采分点的分数总和
score = rubricPoints
  .filter(point => point.hit)
  .reduce((sum, point) => sum + point.awardedScore, 0);

// 验证：正向划线的分数总和 必须等于 小问得分
const positiveMarksScore = answerMarks
  .filter(mark => mark.status === 'score')
  .reduce((sum, mark) => sum + mark.score, 0);

if (positiveMarksScore !== score) {
  throw new Error('得分点划线分数不匹配');
}
```

### 示例场景

**场景：小问满分10分，有2个采分点各5分**

**学生答案A（完美答案）：**
```
"本案中，污染行为的证明责任由赵某承担，因为原告主张的事实由原告举证。
其他养殖户未受影响的事实由白云制药厂承担证明责任，因为这是被告的抗辩事由。"
```

**AI批改：**
- 采分点1：命中 ✓（5分）
- 采分点2：命中 ✓（5分）
- 得分：10分
- 划线：2个正向划线，各5分
- 遗漏：无
- 错误：无

---

**学生答案B（部分正确）：**
```
"本案中，污染行为的证明责任由赵某承担。"
```

**AI批改：**
- 采分点1：命中 ✓（5分）
- 采分点2：未命中 ✗（0分）
- 得分：5分
- 划线：1个正向划线（5分）
- 遗漏：1个（采分点2，丢5分）
- 错误：无（只是遗漏，不是写错）

---

**学生答案C（有错误）：**
```
"本案中，污染行为的证明责任由白云制药厂承担，因为举证责任倒置。"
```

**AI批改应该是：**
- 采分点1：未命中 ✗（0分）
- 采分点2：未命中 ✗（0分）
- 得分：0分
- 划线：
  - 1个错误划线："污染行为的证明责任由白云制药厂承担" → 主体错误
  - 1个错误划线："因为举证责任倒置" → 法律适用错误
- 遗漏：2个（所有采分点都没答对）
- 错误：2个

**但当前AI只会：**
- 采分点1：未命中 ✗（0分）
- 采分点2：未命中 ✗（0分）
- 得分：0分
- 划线：无 ❌（不标注错误）
- 遗漏：2个

## 🎨 划线标注的细节

### 划线类型

**1. 正向划线（status: "score"）**
- **作用：** 标注学生答对的部分
- **颜色：** 绿色高亮
- **必须有：** score字段（得几分）
- **comment：** 说明命中了哪个采分点

**示例：**
```
学生答案："污染行为的证明责任由赵某承担"
         [====绿色高亮，显示+5分=====]
鼠标悬停显示：命中采分点：污染行为证明责任（5分）
```

**2. 错误划线（status: "wrong"）**
- **作用：** 标注学生答错的部分
- **颜色：** 红色高亮
- **不能有：** score字段
- **comment：** 必须详细说明为什么错、正确应该是什么

**示例：**
```
学生答案："污染行为的证明责任由白云制药厂承担"
         [========红色高亮========]
鼠标悬停显示：证明责任主体错误。污染行为的证明责任应由原告赵某承担，而非被告白云制药厂...
```

**3. 中性划线（status: "neutral"）**
- **作用：** 标注需要提示的部分（不扣分也不加分）
- **颜色：** 蓝色高亮
- **不能有：** score字段
- **comment：** 提示或建议

**示例：**
```
学生答案："根据相关法律规定"
         [===蓝色高亮===]
鼠标悬停显示：建议明确引用具体法条，如《民事诉讼法》第X条
```

### 划线要求

**精确性：**
- 只划关键词、短语或短句
- 不要整段划线
- 优先划6-35个中文字符
- 每个采分点对应一条正向划线

**覆盖度：**
```javascript
// 理想情况：学生答案的主要内容都应该被标注
const markedChars = answerMarks.reduce((set, mark) => {
  for (let i = mark.start; i < mark.end; i++) {
    set.add(i);
  }
  return set;
}, new Set());

const coverageRate = markedChars.size / answerText.length;

// 如果覆盖率 < 30%，可能遗漏了重要内容
```

**不重叠：**
```javascript
// 同一段文字不能被多次划线
// 错误示例：
answerMarks: [
  { highlight: "污染行为的证明责任由赵某承担", start: 0, end: 15 },
  { highlight: "证明责任由赵某承担", start: 6, end: 15 }  // ← 重叠了！
]
```

## 📝 点评（reviewComment）要求

### 结构

好的点评应该包含：
1. **肯定部分**（如果有）- 学生哪里答对了
2. **问题部分** - 学生哪里答错了、遗漏了什么
3. **为什么错** - 错误的原因、正确的理解是什么
4. **如何改进** - 下次应该怎么写

### 示例

**好的点评：**
```
你这一问能够意识到证明责任需要结合具体事实来分配，这个方向是对的。
但存在两个问题：
1. 污染行为的证明责任主体写错了。你写的是白云制药厂承担，但根据"谁主张、谁举证"原则，应当由主张污染行为存在的赵某承担举证责任。
2. 遗漏了其他养殖户未受影响这一事实的证明责任分配。这个事实属于被告的抗辩理由，应当由被告白云制药厂承担证明责任。

下次作答时，建议按照这个框架：
- 先判断这个事实是哪一方主张的（原告还是被告）
- 再判断这个事实服务于什么目的（证明请求还是抗辩）
- 最后确定由哪一方承担证明责任，并简要说明理由
```

**不好的点评：**
```
本题得分5分。你答对了一部分，但还有一些采分点没有答上。继续加油。
```
（太笼统，没有指出具体问题）

### 限制

- **字数：** 300-400个中文字符
- **禁止：** 
  - 出现具体分数（"得了5分"、"扣了5分"）
  - 出现AI痕迹（"根据模型判断"、"系统认为"）
  - 只写"错误"、"不准确"而不说明为什么错

## 🔍 AI批改的难点

### 难点1：语义理解

**问题：** 学生可能用不同的表述表达同一个采分点

**采分点：** "污染行为证明责任由赵某承担"

**学生可能这样写：**
- "赵某应当证明白云制药厂存在污染行为"  ✓
- "污染事实的举证责任在原告赵某"  ✓
- "原告需要证明被告排放了废气"  ✓
- "白云制药厂应当证明自己没有污染"  ✗（主体反了）

AI需要理解语义，而不是简单的关键词匹配。

### 难点2：错误识别

**问题：** 需要识别各种类型的错误

**错误类型：**
1. **主体错误** - 把甲方责任说成乙方责任
2. **法律关系错误** - 把合同关系说成侵权关系
3. **法律概念误用** - 把过错责任说成无过错责任
4. **事实认定错误** - 把材料中的事实张冠李戴
5. **结论相反** - 应该承担责任说成不承担
6. **逻辑错误** - 前提和结论矛盾

每种错误都需要AI能识别并给出针对性说明。

### 难点3：部分正确

**问题：** 学生可能答对一半

**采分点：** "赵某应对污染行为承担证明责任，因为原告主张的事实由原告举证"（5分）

**学生答案：** "赵某应对污染行为承担证明责任"（只有结论，没有理由）

**如何给分？**
- 方案A：给满分5分（命中结论即可）
- 方案B：给3分（有结论但缺理由）
- 方案C：给0分（必须结论+理由完整）

这需要在 `rubricGuidance` 中明确说明。

### 难点4：采分点的颗粒度

**粗颗粒度：**
```javascript
rubricPoints: [
  { title: "正确分配证明责任", maxScore: 10 }
]
```
- 优点：灵活，学生多种表述都可能得分
- 缺点：难以精确控制，不同阅卷老师标准不一

**细颗粒度：**
```javascript
rubricPoints: [
  { title: "指出污染行为由赵某证明", maxScore: 2 },
  { title: "说明原告主张的事实由原告举证", maxScore: 2 },
  { title: "指出损害结果由赵某证明", maxScore: 2 },
  { title: "指出因果关系举证责任倒置", maxScore: 2 },
  { title: "指出其他养殖户未受影响由被告证明", maxScore: 2 }
]
```
- 优点：精确，易于判断
- 缺点：繁琐，可能过于机械

当前系统支持两种，但细颗粒度更适合AI批改。

## 🎓 理想的AI批改流程

### 第1步：理解题目和采分点

```
输入：
- 题目材料
- 小问要求
- 采分点列表
- 参考答案
- 批改说明

AI思考：
- 这道题考察什么知识点？
- 每个采分点的核心是什么？
- 学生可能有哪些常见错误？
```

### 第2步：分析学生答案

```
输入：
- 学生答案文本

AI逐句分析：
- 这句话在说什么？
- 这句话是否命中某个采分点？
- 这句话是否存在错误？
- 这句话的作用是什么（论述、举例、过渡）？
```

### 第3步：匹配采分点

```
对于每个采分点：
  if 学生答案中有对应表述:
    if 表述正确:
      hit = true
      awardedScore = maxScore
      生成正向划线
    else:
      hit = false
      awardedScore = 0
      生成错误划线（说明为什么不能给分）
  else:
    hit = false
    awardedScore = 0
    添加到遗漏点
```

### 第4步：识别额外错误

```
扫描学生答案，查找：
- 法律概念误用
- 逻辑矛盾
- 事实错误
- 其他明显问题

为每个错误生成错误划线
```

### 第5步：计算分数

```
score = sum(命中的采分点的分数)
验证：正向划线分数总和 = score
```

### 第6步：生成点评

```
结构：
1. 总体评价（对/部分对/错）
2. 得分点（哪些答对了）
3. 问题点（哪些答错了、为什么错）
4. 遗漏点（哪些没答）
5. 改进建议（下次怎么写）

字数：300-400字
语气：老师对学生，专业但友好
```

## 💡 修复建议

### 短期修复（改Prompt + 验证）

**1. 在Prompt中强调错误标注：**
```
【关键要求 - 必须执行】

当学生答案存在以下情况时，必须生成 status:wrong 的错误划线：
1. 法律主体写反（如把原告义务写成被告义务）
2. 法律关系认定错误（如把合同责任说成侵权责任）
3. 法律概念误用（如把过错责任说成无过错责任）
4. 事实认定错误（如把材料中的事实张冠李戴）
5. 结论完全相反（如应承担责任说成不承担）
6. 逻辑推理错误（如前提和结论矛盾）

错误标注格式：
{
  "highlight": "具体错误的原文",
  "status": "wrong",
  "comment": "说明为什么错 + 正确理解是什么"
}

【示例】
学生写："污染行为应由白云制药厂证明"
采分点："污染行为应由赵某证明"

错误标注：
{
  "highlight": "污染行为应由白云制药厂证明",
  "status": "wrong",
  "comment": "证明责任主体错误。根据'谁主张、谁举证'原则，污染行为的证明责任应由原告赵某承担，而非被告白云制药厂。"
}
```

**2. 增加错误标注验证：**
```javascript
// 如果有未命中的采分点，必须有错误标注或详细说明
if (missedPoints.length > 0 && answerText.length > 50) {
  const wrongMarks = answerMarks.filter(m => m.status === 'wrong');
  if (wrongMarks.length === 0) {
    throw new ValidationError('有遗漏的采分点但没有标注错误');
  }
}
```
