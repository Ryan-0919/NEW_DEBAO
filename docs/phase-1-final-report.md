## ⚠️ 剩余问题（1%）

### 核心问题：reviewComment长度控制

**现象：**
- AI经常超过80字限制
- 即使限制到80字，加上其他字段仍可能超token
- 单小问测试成功率低

**根本原因：**
- AI模型难以严格遵守字数限制
- 中文字符计数不精确
- JSON结构本身也占用tokens

**已尝试的解决方案：**
1. ✅ 从300字→150字→100字→80字
2. ✅ comment从30字→15字→10字
3. ✅ 强调"严格控制"、"会被截断"
4. ✅ 多小问逐个批改

**仍然不完美：**
- 单小问和双小问仍有40%失败率
- 三小问通过是因为逐个批改（每个小问单独请求）
