- 系统版本: AI批改V2

### 测试数据

**题目**：
> 陈某提起的自诉是否属于法定自诉案件的范围？请说明理由。

**学生答案**：
> 陈某提起的自诉属于法定自诉案件范围。因为公安机关不予立案，陈某有证据。

**答案特点**：
- 结论正确
- 理由过于简略
- 缺少法律分析
- 遗漏关键要点

### 2. 批改意见（reviewComment）

**字数**: 643字

**内容**:
```
你这道题答得还不错，基本方向是对的。你能够准确判断出陈某提起的自诉属于法定自诉案件的范围，这个结论是正确的，说明你对自诉案件的基本概念有一定的理解。而且你也注意到了【公安机关不予立案】和【陈某有证据】这两个关键事实，这两点确实是构成公诉转自诉案件的重要条件，所以这部分能给你拿到分数。

不过咱们来看看问题在哪里。你的答案太简略了，理由部分缺乏具体的法律分析。首先，你只说了【陈某有证据】，但没有说清楚这个证据是证明什么的——应该明确指出是【有证据证明被告人侵犯人身权利】，这是法定要件之一。其次，你提到【公安机关不予立案】，但表述不够准确，应该说【公安机关不予追究刑事责任】，这个表述更符合法律规定。最重要的是，你没有点明这个案件符合的是哪一类自诉案件。自诉案件有三类，本案属于第三类，也就是【公诉转自诉案件】，你需要明确说出来。另外，你也没有说明为什么本案符合这一类型的条件，缺少对案件性质的完整分析。

除了上面说的问题，你还遗漏了一个重要的采分点。你需要明确指出本案符合【公诉转自诉案件条件】这个结论，并且最好能简单概括一下什么是公诉转自诉案件，这样答案就完整了。这些遗漏的内容其实都是送分点，如果答全了，分数会提高不少。

下次遇到这类题目，建议你按照【结论+理由+具体分析】的结构来答。先给出明确结论，再分条列出法律依据和案件事实的对应关系，最后总结为什么符合条件。答题时要注意使用准确的法律术语，把采分点都覆盖到。继续加油，你的基础不错，只要答得更细致一些，分数会更高的！
```

**语气分析**:
- ✅ 使用"你"、"咱们"等口语化表达
- ✅ 先肯定优点："答得还不错"、"基本方向是对的"
- ✅ 温和指出问题："不过咱们来看看问题在哪里"
- ✅ 鼓励学生："继续加油，你的基础不错"

## 🔍 详细数据说明

### 1. 基本信息字段

| 字段 | 数据类型 | 示例值 | 说明 |
|------|----------|--------|------|
| `id` | string | "sub_1" | 小问ID |
| `title` | string | "陈某提起的..." | 题目标题 |
| `answer` | string | "陈某提起的自诉..." | 学生原答案 |
| `score` | number | 4 | 本小问得分 |
| `maxScore` | number | 5 | 本小问满分 |
| `reviewSource` | string | "ai-v2" | 批改来源标识 |
| `reviewProvider` | string | "openai-compatible" | AI提供商 |
| `abilityLabel` | string | "第1问" | 能力标签 |

### 2. 批改意见字段（reviewComment）⭐ 核心

| 字段 | 数据类型 | 字数 | 说明 |
|------|----------|------|------|
| `reviewComment` | string | 643字 | 详细批改意见 |

**内容结构**:
1. **开头肯定**（约100字）
   - 表扬学生答对的部分
   - 说明为什么能得分
   
2. **指出问题**（约300字）⭐ 重点
   - 详细说明哪里答错了
   - 解释为什么错
   - 告诉正确答案应该是什么
   
3. **说明遗漏**（约150字）
   - 指出遗漏的采分点
   - 解释遗漏的影响
   
4. **给出建议**（约100字）
   - 具体的改进方法
   - 答题技巧
   - 鼓励的话

**字段说明**:

| 字段 | 数据类型 | 可选值 | 说明 |
|------|----------|--------|------|
| `id` | string | "m1", "m2"... | 标注唯一ID |
| `status` | string | "score", "wrong", "missing" | 标注类型 |
| `score` | number | 0-5 | 该标注得分 |
| `comment` | string | 3-4字 | 简短批注 |
| `highlight` | string | 原文片段 | 从答案中提取的文本 |

**status类型说明**:
- `"score"`: 得分点（绿色✓），学生答对的地方
- `"wrong"`: 错误点（红色✗），学生答错的地方
- `"missing"`: 遗漏点（橙色⚠️），学生没答的地方

**本次测试统计**:
- ✅ 得分点: 3个（50%）
- ❌ 错误点: 3个（50%）
- ⚠️ 遗漏点: 0个（0%）
- **错误标注率**: 100% ✅
