# 用户端展示数据核对续做记录 - 2026-05-26

## 本轮目标

继续核对用户端前台展示数据，清理仍可能误导学员的 mock、占位、技术文案和旧演示链路。本轮明确不做微信状态绑定。

## 已处理

1. 课程学习链路
   - 课程卡片移除写死评分和学习人数。
   - 音频课、视频课不再展示“本地示例”来源文案。
   - 无课程上下文时不再回退到本地示例课程，而是显示课程不可访问状态。
   - 课程加载失败文案从内部“后端同步失败”改为普通用户可理解的“课程加载失败”。

2. 设置与个人资料
   - 设置页移除通知、播放、隐私等只改前端 state、不保存的假开关。
   - 微信绑定状态本轮不做，也不展示成可操作功能。
   - 个人资料页移除假头像上传按钮和假手机号更换按钮。
   - 个人资料保存提示改为“资料已保存”，不再暴露旧用户系统。

3. 旧主观批改演示链路
   - `/grading/detail`、`/grading/answer` 不再进入写死的主观批改产品和假作答页。
   - `/grading/*` 统一导回真实主观题试卷列表 `/user/mock-exams`。
   - 用户端主观题入口继续走真实机考/批改流程。

4. 机考启动页
   - 去掉准考证号、证件号的 `888888` 假兜底。
   - 无法从手机号生成时，保留为空，由用户按页面要求输入。

5. 用户可见技术文案
   - API 连接失败文案改为“服务暂时不可用，请稍后重试或联系教务老师”。
   - 讲义下载备用提示去掉“接口/原始地址”等技术表述。
   - 题库、公告、订单、机考试卷空状态去掉“后台/真实”等内部词。
   - 旧备用机考首页的默认英文 `Mock Exam` 改为“机考中心”。
