## 📊 JSON结构说明

### 1. 顶层结构
```
整个批改结果
├── 元数据（source, version, totalScore等）
├── 语音点评信息（当前未使用）
├── 学生反馈信息（feedbackStars等）
└── subQuestions[]（小问列表）
```

### 2. 单个小问结构
```
单个小问
├── 基础信息（id, title, answer, score）
├── reviewComment（点评文本）
├── missedPoints[]（遗漏点列表）
├── answerMarks[]（答案标注列表）
│   ├── score类型（✓ 得分点）
│   ├── wrong类型（✗ 错误点）
│   └── neutral类型（⚠ 中性点）
├── rubricGuidance（批改指导）
└── rubricPoints[]（采分点命中情况）
```

### 3. 标注类型说明

| status | 中文名 | 颜色 | 含义 | 示例 |
|--------|--------|------|------|------|
| score | 得分点 | 绿色 | 学生答对了 | "结论正确" |
| wrong | 错误点 | 红色 | 学生答错了 | "主体错误" |
| neutral | 中性点 | 黄色 | 需要注意 | "表述不够精确" |

## 🎯 关键字段说明

### answerMarks（答案标注）
这是**最重要的字段**，用于在学生答案上划线标注：
- `highlight`：要高亮的文本（必须是学生答案原文）
- `status`：标注类型（score/wrong/neutral）
- `score`：如果是得分点，给多少分
- `comment`：简短评语（3-6字）

### missedPoints（遗漏点）
告诉学生哪些采分点没答到：
- `title`：简短标题
- `description`：详细说明应该怎么答

### rubricPoints（采分点）
题目预设的采分点，标记学生是否答到：
- `hit`：true（答到了）/ false（没答到）
- `awardedScore`：实际给分
